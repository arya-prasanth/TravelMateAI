# TravelMateAI

TravelMateAI is an AI-powered travel planning web application developed using Python and Flask. It helps users explore destinations by generating personalized travel guides, popular attractions, local food recommendations, real-time weather information, and travel tips.

## Features

* AI-generated travel guide
* Destination image gallery
* Real-time weather updates
* Popular attractions
* Local food recommendations
* Travel tips
* Save favourite destinations
* Dark mode
* Responsive user interface

## Technologies Used

* Python
* Flask
* HTML5
* CSS3
* JavaScript
* Groq AI API
* OpenWeather API
* Unsplash API

## Installation

1. Clone the repository.
2. Install the required dependencies.
3. Create a `.env` file with your API keys.
4. Run the Flask application.

```bash
pip install -r requirements.txt
python backend/app.py
```

Open your browser and visit:

```text
http://127.0.0.1:5000
```
